# itch.io cover

`cover-630x500.png` is the 630 × 500 PNG cover for the Android game listing.
Created with the built-in image-generation tool using a fresh iPhone 17 Pro simulator
title-screen capture on September 13, 2026, then resized with macOS sips.

Prompt: Create a compelling itch.io cover faithful to the simulator title screen: deep
navy-purple background, pastel translucent jelly lettering spelling DDDUMPLING, six original
characters in pastel-outlined hexagonal keys (dumpling, strawberry, cat, grapes, mint face,
blue bear), and the text “TYPE • SWIPE • COLLECT”. Recompose for landscape 630 × 500 with
readable title, safe margins, restrained sparkles and strong hierarchy. Remove phone cutout,
menus, scores and other screenshot UI. Preserve the game's simple cartoon identity; avoid
new characters, invented gameplay, logos, badges and watermarks.

Verified final dimensions, title spelling, tagline and character count. This is promotional
art based on the game screen, not an unmodified gameplay screenshot.
